# 入力検証と保存設定

変換キューへの追加前に、画面とメインプロセスで共通の検証を行います。

- FPSとコメントのスケールは正の有限数、解像度は正の整数。
- 切り抜きは `0 <= 開始位置 < 終了位置 <= 動画の長さ`。空欄は先頭・末尾。
- 不正な時刻文字列は消去せず、修正を促します。登録に失敗した場合も動画・コメントの選択を保持します。
- 検証に失敗したキューは登録せず、依存するダウンロードも開始しません。

保存設定は `AppSettings` と実行時バリデータで管理します。既定値は認証なし、標準FFmpegオプション、レンダラ表示あり、コメント拡張子 `.json`、自動更新 `unset`（未回答）です。

- 従来のバージョンなしファイルをバージョン0として読み、`settingsVersion: 1` を保存します。旧FFmpegオプションの有限数値は文字列へ移行します。
- 正常な設定は保持し、不正・欠落した項目だけを既定値へ戻します。`false`、空のオプション辞書、空文字列のFFmpegフラグは有効です。
- JSON自体が壊れている場合は全設定を既定値へ戻します。新しいバージョンの設定ファイルは上書きせず、読み込みを拒否します。
- 新しい保存要求では型の不一致を拒否します。未知の設定キーやドット区切りによる入れ子の更新も受け付けません。

## 更新確認（オプトイン）

- `updateCheck` は `unset` / `enabled` / `disabled`。`unset` の初回起動時のみ、更新確認の可否を尋ねるダイアログを表示し、回答を保存します。
- `enabled` のときだけ起動時に GitHub Releases の最新版を確認し、新しければダイアログでダウンロードページを開くか尋ねます。自動ダウンロード・インストールは行わないため、ポータブル版（zip）や未署名のmacOSでも動作します。
- 設定画面の「その他」からいつでも切り替えられ、有効化した直後にも確認します。開発ビルド（未パッケージ）では何もしません。
